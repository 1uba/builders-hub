## Overview

Tatum is a blockchain development platform that simplifies Web3 application development with unified APIs and SDKs. It supports 40+ blockchain networks including Avalanche, letting developers build, test, and deploy blockchain applications without managing infrastructure or learning multiple chain-specific APIs.

## Features

- **Unified API**: Single API for 40+ blockchains
- **Pre-Built Functions**: Ready-to-use blockchain operations
- **Multi-Language SDKs**: SDKs for JavaScript, Java, PHP, and more
- **Wallet Management**: Create and manage wallets programmatically
- **NFT APIs**: Complete NFT minting and management
- **Virtual Accounts**: Off-chain accounting for scalability

## Public RPC Endpoints

Tatum runs public Avalanche endpoints that work without an API key at 5 requests per minute, for development and testing. Paid plans raise the limit.

| Chain | Mainnet | Fuji Testnet |
|---|---|---|
| C-Chain | `https://avalanche-mainnet.gateway.tatum.io` | `https://avalanche-testnet.gateway.tatum.io` |
| P-Chain | `https://avalanche-mainnet.gateway.tatum.io/ext/bc/P` | `https://avalanche-testnet.gateway.tatum.io/ext/bc/P` |
| X-Chain | `https://avalanche-mainnet.gateway.tatum.io/ext/bc/X` | `https://avalanche-testnet.gateway.tatum.io/ext/bc/X` |

Plans and higher limits: [Tatum Avalanche RPC](https://tatum.io/chain/avalanche). Every free Avalanche endpoint in one list: [freerpc.com/avalanche](https://freerpc.com/avalanche).

## Getting Started

To use Tatum:

1. **Sign Up**: Create account at [Tatum](https://tatum.io/)
2. **Get API Key**: Access your credentials from dashboard
3. **Choose SDK**: Select SDK for your programming language
4. **Start Building**: Use Tatum APIs to build your application
5. **Deploy**: Launch your Web3 application
